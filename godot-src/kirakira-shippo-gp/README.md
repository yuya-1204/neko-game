# キラキラしっぽグランプリ

Godot 4.7.1で制作した、子ども向けの3Dアーケードレーシングゲームです。

## 内容

- 読み込み後は操作説明とコース選択画面で待機し、「レーススタート！」で開始
- 茶色の地面と濃い道路で境界が見やすい3つのコースを収録
- コース1：大きなカーブ中心のシンプルなオーバル
- コース2：中央がくびれた、ひょうたん型のコース
- コース3：障害物があり、外回りと近道の分岐を選べるコース
- プレイヤー1台とAIレーサー3台
- 順位、ラップ、タイム、コース別の最高タイム
- ドリフトからのミニターボ
- キラリ収集と加速パネル
- スマホ横持ち向けの左右半画面タッチ操作
- 自動アクセル、コース復帰、走行ライン補助
- スタートボタンを押した後に3秒カウントダウン
- オリジナルBGM、ドリフト音、ターボ音を収録
- 音は初期状態でオン（ブラウザでは最初のタッチ後に再生開始）

## 操作

- スマホで曲がる: 画面の左半分または右半分をタッチ
- スマホで右ドリフト: 右半分を押しながら左下の「ドリフト」
- スマホで左ドリフト: 左半分を押しながら右下の「ドリフト」
- キーボードで曲がる: `A` / `D` または左右キー
- キーボードでブレーキ: `S` または下キー
- キーボードでドリフト: `Space`
- コースへ戻る: `R`
- ゲームパッドにも対応

効果音とBGMは右上の「おと：オン／オフ」でまとめて切り替えられます。

## オーディオ

BGM・ドリフト音・ターボ音は外部素材を使用せず、このプロジェクト用に波形から生成したオリジナル音源です。音源を再生成する場合は、Godotプロジェクトを指定して次を実行します。

```powershell
godot --headless --path . --script res://tools/generate_audio_assets.gd
```

## Web書き出し

Godot 4.7.1のStandard Export Templatesを導入後、プロジェクトの親リポジトリで次を実行します。

```powershell
godot --headless --path .\godot-src\kirakira-shippo-gp --export-release Web .\kirakira-shippo-gp\index.html
```

Web版はCompatibility renderer、single-thread構成です。外部通信、広告、解析、アカウント機能はありません。
