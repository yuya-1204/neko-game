# にゃんこ発明ラボ2 — はこねこ大実験

道具を自由に置いて、毛糸玉をシャロ・ゆき・ほたてに届けるブラウザ物理パズルです。

- こもれび工房・そよかぜの庭・星あかりの屋根裏：計18ステージ
- 坂・ばね・扇風機・クッションの4種類。位置と角度、衝突と風によって結果が変わります。
- ゴール判定は物理的な箱への着地。お手本との配置一致では判定しません。
- 1個のクリア星と2個の任意の星。星を取り逃しても先に進めます。
- ドラッグ、タップで移動、矢印で微調整、角度スライダー、元に戻す／やり直す、軌跡表示、巻き戻し。
- 段階的なヒントと、必要なときに置けるお手本。
- 自由制作では道具・出発点・ゴールを変更し、名前を付けて6作品まで端末内に保存できます。
- VOICEVOX:ずんだもんの短い案内22本を同梱。字幕、声・BGM・効果音の個別調整、消音、装飾アニメーションの抑制。

対象の目安は6〜9歳。スマートフォンは横向きがおすすめです。PC・タブレットにも対応します。アカウントやVOICEVOXの起動は不要です。

## ローカル実行

このフォルダをHTTPサーバーで配信して `index.html` を開いてください（ES modulesを使うためfile://では実行しません）。外部CDNやビルド工程はありません。

```sh
python -m http.server 8768
node --test tests/physics.test.mjs
```

## ファイル

- `physics.mjs`: 固定時間刻みの円と回転矩形の物理演算、風、跳躍、着地判定
- `levels.mjs`: 18ステージ、各2個の星、お手本、自由制作の初期状態
- `app.js`: 操作・画面・保存・進行
- `art.mjs`: オリジナルCanvasイラスト
- `audio.mjs` / `voice-lines.json` / `voice/`: 音楽、効果音、音声と字幕
- `tools/synthesize-voice.py`: 制作時だけ使用する音声再生成ツール
- `tools/compress-voice.py`: WAV原本を公開用MP3へ変換するツール（実行時の音声は22本、合計約384KB）

進捗と作品は `hakoneko-lab-v1`、音声設定は `hakoneko-audio-v1` のlocalStorageに保存します。ブラウザのデータ削除で消去されます。サーバーには送信しません。
