# レモエールくんゲーム

ソフィアホームケアクリニックとエールのオリジナルキャラクター「レモエール君」「レモミィちゃん」を使用した、登録不要のブラウザゲームです。権利者・管理者の許可を得て、山岸産業医事務所が企画・制作しています。

## 収録内容

- `index.html`: ゲーム選択ページ
- `kitchen.html`: レモエールキッチン
  - レモネードスタンド
  - ハンバーガーづくり
  - カレーの具材探し
  - おべんとうをつめよう
  - フルーツパフェを作ろう
  - ピザを分けよう
  - 朝ごはんをそろえよう
  - 冷蔵庫のおかたづけ
  - レストランのお会計
- `catch.html`: レモンキャッチ

キッチンゲームは各7レベルです。前半は見本を見ながら1つの条件に合わせ、後半は記憶、複数条件、等分、硬貨の組み合わせへ段階的に難しくなります。進み具合とベストスコアはブラウザ内だけに保存されます。

## 操作と安全設計

- スマートフォン、タブレット、パソコン対応
- 登録、広告、個人情報の送信なし
- キッチンの基本モードは時間制限なし
- 間違えてもゲームオーバーにせず、ヒントを表示
- レモンキャッチは画面ドラッグ、大きな左右ボタン、キーボードに対応

キャラクター画像の権利は各権利者に帰属します。
