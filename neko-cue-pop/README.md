# ネコの合図でポン！ ふしぎなリズム劇場

6〜9歳向けの、画面全体を1ボタンとして使うリズムコメディゲームです。

- 13公演（9つの独立ステージ、3つのリミックス、グランドフィナーレ）
- タップ／クリック／スペースキーのみ
- ノーツレーン、長押し、スワイプなし
- 6歳向け「おたすけ」と、クリア後の「チャレンジ」
- `AudioContext.currentTime` を基準にしたタイミング判定
- 途中失敗なし、ローカル保存、字幕、ミュート、一時停止、全画面
- Dr.やまねことゆきちゃんによる音声付き導入

## 公開エントリ

`index.html`

## 音声

音声はVOICEVOXで事前生成した静的WAVです。ゲーム実行時にVOICEVOXへ接続しません。

- Dr.やまねこ：VOICEVOX:ずんだもん
- ゆきちゃん：VOICEVOX:四国めたん

再生成はVOICEVOX Engine起動中に次を実行します。

```powershell
./tools/generate_voicevox.ps1
```

## 手動確認

1. タイトルの「音をONにして はじめる」から音声導入が再生される
2. 全13ステージが順番に解放される
3. タップ、クリック、スペースキーで同じ判定になる
4. おたすけ／チャレンジの判定差が反映される
5. 一時停止、復帰、リトライ、離脱が動作する
6. 320px相当と横長スマホで操作ボタンが隠れない
7. クレジットに両VOICEVOX表記がある
