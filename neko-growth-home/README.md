# ネコ成長パズル2 — ひみつのネコのおうち

同じネコをスワイプで合わせる進化パズル。4×4の盤面で10種類のネコを見つけ、「おひっこし」で空き場所を作りながらネコのおうちを育てます。

公開URL: https://yuya-1204.github.io/neko-game/neko-growth-home/

## あそびかた

- 上下左右にスワイプ、矢印キー、WASD、画面の矢印ボタンで操作。
- 同じレベルのネコを合わせると1段階進化。ねずみはどのネコとも合体します（ねずみ同士は不可）。
- 6回の合体でおさかなゲージが満タン。次の移動で最初に起きる合体だけ2段階進化します。最高レベルは10。
- お願いと同じネコをおひっこしすると、そのマスが空き、ネコが家に住み始めます。複数いる場合は選べます。
- おひっこし2・4・6・8・12・16匹で家具が増えます。家のネコをタッチすると反応します。
- 時間制限なし。1手戻す（引っ越しも含む）、ネコ図鑑、BGM・効果音の消音、自動保存付き。
- 新しいパズルでも住人・家具・図鑑・ベストを維持。データは同じブラウザの localStorage に保存されます。別端末への同期はありません。

## 実装

外部ライブラリ、画像CDN、Webフォント、アカウント登録、サーバー処理不要。ES modules とオリジナルSVG、Web Audioで構成。

- `engine.mjs`: シード乱数と不変状態を使う純粋なゲーム規則
- `app.mjs`: 入力、表示、保存、ダイアログ
- `art.mjs`: 10種類のネコ・ねずみ・段階的に増える家具
- `audio.mjs`: オリジナルBGMと効果音

任意の静的HTTPサーバーでルートを公開してください。例: `python -m http.server 8772 --bind 127.0.0.1`。

テスト: `node --test tests/engine.test.mjs`。音はユーザーが開始ボタンを押した後だけ再生されます。タブが隠れたときは停止します。動きを減らすOS設定にも対応します。
