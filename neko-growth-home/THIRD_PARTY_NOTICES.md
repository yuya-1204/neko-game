# 作品・素材について

「ネコ成長パズル2 ひみつのネコのおうち」のネコ、おうち、家具、アイコンは、このゲームのために作成したオリジナルの SVG イラストです。既存のキャラクターや画像素材は使用していません。

BGM と効果音は、このゲームのために作曲・設計した音をブラウザーの Web Audio API で合成しています。録音素材、外部音源、音声合成サービスは使用していません。

外部の画像・フォント・音声ファイルの読み込み、外部 JavaScript ライブラリ、広告、解析用トラッカーはありません。文字の表示には各端末のシステムフォントを使います。
