# ネコをさがせ！だいぼうけん2 〜ネズミのおねがい〜

「ネコをさがせ！だいぼうけん」の続編となる、子ども向け（5〜9歳）ブラウザRPGのプロトタイプです。
戦闘なし・ひらがな／カタカナのみのテキストで、ネズミたちの「おねがい」を解決しながら進むクエスト形式のゲームです。

- 1ファイル完結（`index.html`）。Phaser 3 を cdnjs CDN から読み込むだけで、ビルド不要でそのまま動きます
- 想定プレイ時間: 30分前後
- © 山岸産業医事務所 ／ 音声：VOICEVOX:ずんだもん

## 遊び方

### 操作

| 操作 | PC | スマホ |
|---|---|---|
| あるく | 矢印キー または WASD | 画面左下の十字キー |
| はなす・しらべる | スペース または Enter | 画面右下の「はなす・しらべる」ボタン |
| ネコこうたい | 1・2・3キー（Cキーで順番に切替も可） | 画面上部のネコボタン |
| ヒント | 画面上部「ヒント」ボタン | 同左 |
| おと ON/OFF | 画面上部「おと」ボタン | 同左 |

### 3びきのネコと とくいわざ

- **シャロ**（ちゃトラ）… ちからもち。おもい岩や箱を押せる
- **ゆき**（くろネコ）… くらやみに強い。どうくつやトンネルの中でも視界が保てる
- **ほたて**（しろネコ）… すばやい。せまいすきまを通れる

案内役として白衣のネコ博士「ドクターやまねこ」が登場します（ヒントボタンでも助言）。

### セーブ

クエスト達成・エリア移動時に localStorage へ自動セーブされます。タイトル画面の「つづきから」で再開できます。
（localStorage が使えない環境でも起動します。その場合セーブされないだけです）

## ファイル構成

```

├── index.html      … ゲーム本体（単一ファイル）
├── README.md       … このファイル
└── voice/
```

## GitHub Pages へのアップ手順

既存リポジトリ `yuya-1204/neko-game` に **`neko-rpg2/` フォルダごと**追加します。

### ブラウザだけで行う場合

1. GitHub で `yuya-1204/neko-game` リポジトリを開く
2. 「Add file」→「Upload files」を選ぶ
3. `neko-rpg2` フォルダごとドラッグ＆ドロップする（フォルダ構造が保たれます）
4. 「Commit changes」を押す
5. 数分後、以下のURLで遊べます
   - `https://yuya-1204.github.io/neko-game/neko-rpg2/`
   - （または `https://yuya-1204.github.io/neko-game/neko-rpg2/index.html`）

### git コマンドで行う場合

```bash
git clone https://github.com/yuya-1204/neko-game.git
cd neko-game
# このフォルダ（neko-rpg2）をリポジトリ直下にコピーしてから
git add neko-rpg2
git commit -m "ネコをさがせ！だいぼうけん2 を追加"
git push
```

前作からのリンクを張る場合は、`neko-rpg.html` に
`<a href="./neko-rpg2/">つづきの ぼうけんへ！</a>` などを追記してください。

## ずんだもん音声について（VOICEVOX）

同梱の `voice/01.wav〜20.wav` は VOICEVOX（ずんだもん・ノーマル）で生成済みです。
台詞を変えたい・録り直したい場合は、VOICEVOXアプリで以下の手順で書き出せます。

1. [VOICEVOX](https://voicevox.hiroshiba.jp/)（無料）をインストールして起動
2. キャラクターに「ずんだもん（ノーマル）」を選択
3. `voice/lines.md` の台詞を入力（1行＝1ファイル）
4. メニューの「音声書き出し」で wav を保存
5. `01.wav`〜`20.wav` のファイル名にリネームして `voice/` フォルダに配置

利用時はクレジット表記「**音声：VOICEVOX:ずんだもん**」が必要です（ゲーム内のタイトル画面とエンディングに表記済み）。
VOICEVOX・ずんだもん音声の利用規約（クレジット表記の上で商用・非商用利用可）に従ってください。

## 技術メモ

- Phaser 3.80.1（cdnjs）／ グラフィックは canvas 生成のドット絵＋絵文字（外部画像なし）
- 効果音は WebAudio でその場で生成
- 音声再生は `./voice/NN.wav` を Audio で再生。404 でもエラーにならず無音でスキップ
- `file://` で直接開いた場合、ブラウザによっては音声 wav の再生がブロックされることがあります。
  GitHub Pages 上（または `python -m http.server` などのローカルサーバ）では正常に再生されます
