# ねこをさがせ！だいぼうけん3 ～おばけホテルの7つのかぎ～

6歳ごろから親子で遊べる、見下ろし型の2Dたんけんゲームです。かわいいおばけたちが暮らすホテルを、シャロ・ゆき・ほたての3びきで探検します。戦闘、ゲームオーバー、時間制限、突然驚かせる演出はありません。

## あらすじ

おばけホテルで暮らすこねこの「ミルク」と、ホテルの7つのかぎが消えてしまいました。おばけたちの9つのお願いを聞きながら、AからGのかぎを集め、ミルクを探します。

## 3びきの得意技

- シャロ：重い箱や岩を押せる
- ゆき：暗い部屋でも広く見渡せる
- ほたて：細いすきまを通れる

すきまの中では、進行不能を防ぐため、ほたて以外へ交代できません。

## 9つの章

1. おばけホテルへようこそ
2. キッチンの材料探し（Aのかぎ）
3. 色の英語を使ったダンスホールのなぞ（Bのかぎ）
4. 暗い廊下の光集め（Cのかぎ）
5. 数字の英語を使った遊び部屋のなぞ（Dのかぎ）
6. AからGまでのアルファベットのなぞ（Eのかぎ）
7. 月夜の庭の星集め（Fのかぎ）
8. 3びきの得意技を使う地下室（Gのかぎ）
9. 7つのかぎと、こねこのミルク

学習部分には、色の英語とカタカナ読み、ONE（ワン）からTEN（テン）、A（エー）からG（ジー）を収録しています。間違えても何度でも答えられます。

## 操作

### スマートフォン・タブレット

- 画面左下の矢印：移動
- 「はなす・しらべる」：会話、調べる
- 画面上部の「シャロ」「ゆき」「ほたて」：ねこの交代
- 「ヒント」：同じ場面で押すたび、3段階で詳しく表示
- 「やりなおす」：部屋の箱や岩を初期位置へ戻す
- 「こまった！」：集めた物やかぎを失わず、安全なロビーへ戻る

### パソコン

- 矢印キー / WASD：移動
- Space / Enter：会話、調べる
- 1 / 2 / 3：シャロ / ゆき / ほたてに交代
- H：ヒント
- R：しかけをやりなおす
- L：ロビーへ戻る

## 保存と安全設計

- `localStorage` に自動保存し、「つづきから」で再開できます。
- 保存データはバージョン付きで読み込み、欠けた項目を安全な初期値で補います。
- 保存位置が不正、未開放エリア、歩けないタイルだった場合は、最寄りの安全地点またはロビーへ直します。
- すべての出入り口は、座標を直接書かず、名前付きの安全地点へ移動します。
- 起動時に全マップの行数・列数、出入り口の到着地点、エリア間の接続を検査します。
- 押すしかけは部屋ごとにリセットできます。
- 「こまった！」ボタンは常に画面上部にあります。

## 技術構成

- Phaser 3.80.1（CDN）
- HTML / CSS / JavaScript 1ファイル
- キャラクター、タイル、アイテムはCanvasで生成するオリジナルのドット絵
- Web Audio APIによる短い効果音
- 外部画像・音声ファイルは不要

ローカルで確認する場合は、HTTPサーバーを起動して `index.html` を開いてください。Phaser本体をCDNから読み込むため、初回表示にはインターネット接続が必要です。
