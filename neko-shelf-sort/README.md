# にゃんこ棚のおかたづけ — 3つで、すっきり！

山岸産業医事務所の「ネコゲーム・子ども向け」36番。シャロ・ゆき・ほたてのお店で、小物を3つそろえて棚を片づけるブラウザーゲームです。

- [ゲームを遊ぶ](https://yuya-1204.github.io/neko-game/neko-shelf-sort/)
- [GitHubのソース](https://github.com/yuya-1204/neko-game/tree/main/neko-shelf-sort)
- [子ども向けゲームの掲載ページ](https://yamayu-sangyoui-oyama.localinfo.jp/pages/9869339/page_202607060244)

## 遊び方

1. 手前に見えている小物を選び、空いている場所を押すと移動します。マウスや指でドラッグしても操作できます。
2. **同じ棚の手前に、同じ小物を3つ**そろえると消えます。色違いは別の種類です。
3. 棚の手前3マスがすべて空になると、その棚の奥の列が前に出ます。奥の商品は、前に出るまで見えません。
4. 奥も含めてすべての商品を消すとクリア。商品の消去・奥の列の前進が終わった時点で、**空きマスが0になるか、残り時間が0になると失敗**です。

移動先は、どの棚の空きマスでも選べます。棚を一つ空けておくと、商品を並べ替えやすくなります。

## ステージとおたすけ

- 全24ステージ、4章。好きなステージから遊べます。
- 難度に応じて3〜12種類、4〜8棚、手前を含め最大4層。1ステージの商品数は9〜75個です。
- 小物は全30種類。飲み物・おもちゃ・お菓子・ぬいぐるみ・お花が各6種類あり、似た色違いにもラベルや模様などの違いがあります。
- 通常モードの制限時間は150〜240秒。「1て もどす」とヒントは、それぞれ1ステージにつき3回使えます。もどしても、経過した時間は戻りません。
- 「じかんなし」の練習ではタイマーが進まず、もどす・ヒントの使用回数制限もありません。空きマスがなくなるルールは同じです。
- 休憩中・説明などのダイアログ表示中・ページが非表示の間は、タイマーが止まります。
- 通常モードのクリア時は残り時間の割合で星を記録します。45%以上で星3個、18%以上で星2個、それ未満で星1個。練習では星の記録を更新しません。

盤面は空の状態から逆向きに組み立て、実際の移動・消去・前進ルールで解けることを確かめて生成します。プレイヤーの移動によっては、空きがなくなることがあります。

## 音声と記録

**音声：VOICEVOX:ずんだもん**

説明・応援・結果などの音声24本をMP3で同梱しています。音声ファイルの合計は470,352バイト。遊ぶ際にVOICEVOXの起動やインストールは不要です。音声には字幕があり、音声・BGM・効果音の音量と全体の消音を設定できます。

クリア記録・見つけた商品の図鑑・最後に選んだ通常ステージ・説明の既読・動きを抑える設定・音の設定は、同じブラウザーの`localStorage`に保存します。プレイ中の盤面そのものは保存しません。ブラウザーの保存データを消すと記録も消えます。アカウント登録は不要です。

## ローカルで動かす

静的なHTML/CSS/JavaScriptで構成しており、ビルドやnpm依存パッケージは不要です。ES Modulesと音声ファイルを使用するため、HTMLを直接開く代わりにHTTPサーバーで配信してください。

`neko-game`リポジトリのルートで実行します。

```sh
python -m http.server 8000 --bind 127.0.0.1
```

ブラウザーで`http://127.0.0.1:8000/neko-shelf-sort/`を開きます。

## テスト

Node.jsの標準テストランナーを使用します。リポジトリのルートで実行してください。

```sh
node --test neko-shelf-sort/tests/engine.test.mjs
```

テストでは、3つ一致・空きへの移動・奥の列の前進・時間切れ・空きなし・勝利・盤面生成などのゲームルールを検証します。画面の見た目、タッチ操作、音声再生はブラウザーでも確認してください。

## ファイル

| ファイル | 内容 |
| --- | --- |
| `index.html` / `style.css` | 画面とレスポンシブ表示 |
| `app.js` | 操作、タイマー、ステージ選択、記録と図鑑 |
| `engine.mjs` | 盤面生成、移動、消去、勝敗判定とヒント |
| `levels.mjs` | 24ステージの設定 |
| `art.mjs` | オリジナルの小物・猫・棚のSVGイラスト |
| `audio.mjs` / `voice-lines.json` | 音の制御と音声台本 |
| `voice/` | ずんだもんの案内音声24本 |
| `tools/` | 制作者向けの音声生成・圧縮スクリプト |
| `tests/engine.test.mjs` | ゲームルールのテスト |

音声を作り直す場合は[音声の再生成手順](tools/README.md)を参照してください。再生成時だけ制作者の環境でVOICEVOXを使用します。

## クレジット

イラスト、BGM、効果音は本ゲーム用に制作しています。猫はシャロ（橙のトラ猫）、ゆき（黒猫）、ほたて（白猫）です。

音声の利用・再配布時は、[音声クレジットと利用規約](THIRD_PARTY_NOTICES.md)を確認し、`VOICEVOX:ずんだもん`の表示を維持してください。
