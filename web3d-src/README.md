# ネコ Web3D コレクション

6〜8歳向けの、iPhone・iPad・PCブラウザで遊べる3Dゲーム5作品です。

## 作品

- `neko-kumojima/` — ねこ雲島と ひかりのしっぽ
- `fushigi-photo-safari/` — ふしぎ生きもの フォトサファリ
- `nyanko-karakuri-island/` — にゃんこ発明ラボ・からくり島
- `shinkai-hikari-rescue/` — 深海ひかりレスキュー
- `iro-seirei-zukan/` — おうちの色から生まれる 精霊図鑑

各作品は6地域×5ステージの30ステージ、全5作品で150ステージです。ひらがな、カタカナ、20までの足し算・引き算、時計の読み方を、ゲーム内の仕掛けとして扱います。

## 技術

- Babylon.js 9 / TypeScript / Vite
- Safari 26以降ではWebGPUを優先し、失敗時はWebGL 2へ切り替え
- 自動画質調整、FXAA、Bloom、PBR、プロシージャル3D
- タッチ、キーボード、任意の傾き操作
- 端末内セーブ、オフラインキャッシュ、ホーム画面Webアプリ
- 広告、課金、ランキング、チャット、行動解析なし

## iPhoneの全画面表示

ゲーム内の「全画面」ボタンは、Fullscreen API対応ブラウザでは「元に戻す」と切り替わります。iPhone版Safariは通常タブからゲーム画面だけを全画面化できないため、ボタンから「共有 → ホーム画面に追加」の案内を表示します。ホーム画面のアイコンからWebアプリとして起動すると、Safariのタブやアドレス欄を出さずに横画面で遊べます。

## カメラとプライバシー

「精霊図鑑」だけが、子どもまたは保護者が明示的に選んだ場合に背面カメラを利用できます。中央の小範囲から端末内で粗い色分類を行うだけで、画像、映像、音声、位置情報、RGB値は保存・送信しません。カメラを拒否または利用できない場合でも、イラストと色パレットで全ステージ・全報酬を遊べます。

## 開発

```powershell
pnpm install
pnpm run validate:content
pnpm run typecheck
pnpm run build
```

Viteは既存GitHub PagesのURLを維持したまま、リポジトリ直下の5つの公開ディレクトリと共有 `web3d-assets/` を更新します。
